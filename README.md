# HOOD_MAN_PROJECT

Python과 pico2d로 구현한 2.5D 벨트스크롤 액션 게임입니다. 개발 명세는 [PRD.md](PRD.md), 단계별 기록은 [DEVELOPMENT.md](DEVELOPMENT.md), 검증 결과는 [TESTING.md](TESTING.md)를 참고하세요.

## 실행 환경

- Windows 64비트
- 확인한 버전: Python 3.13.15, pico2d 1.5.1
- 1280×720 창, 60 FPS 렌더링 목표, 120Hz 고정 물리 갱신

## 설치와 실행 (PowerShell)

프로젝트 폴더에서 실행합니다. Python이 없다면 Python 3.13 64비트를 먼저 설치합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

리소스는 소스 파일 위치를 기준으로 읽으므로 다른 작업 폴더에서 `main.py`의 전체 경로로 실행해도 됩니다.
일반 실행 시 타이틀 이미지를 2초 표시한 뒤 자동으로 게임이 시작됩니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| ← / → | 바닥 좌우 걷기 |
| ↑ / ↓ | 바닥 안쪽 / 바깥쪽 걷기, 좌우와 조합해 대각선 이동 |
| 계단 아래 ↑ / 계단 위 ↓ | 2층 오르기 / 1층 내려오기, 주인공 단독·적 간격 이동 |
| 왼쪽/오른쪽 Shift + 방향키 | 가속하여 달리기 |
| Space | 점프, 공중에서 다시 누르면 이단 점프 |
| 첫 맵 이단 점프 후 ↑ / 2층 앞쪽 끝 ↓ | 2층 발판 착지 선택 / 1층으로 낙하 |
| A | 비무장 잽 / 무기 찌르기(10), 제압 유지 중에는 선택한 반격의 후속 공격(80) |
| S | 비무장 스트레이트 / 단검 베기·쇠파이프 휘두르기, 피해 40 |
| D | 비무장 왼발 차기 / 무기 보유·이단 점프 후 슬로 모션 조준, 다시 눌러 내려찍기(50) |
| F | 오른발 차기, 피해 60 |
| Q / W / E / R / T | 강화 기본 공격 5종, 모두 피해 50·W 유지 중 ←/→로 좌우 비행 |
| H | 타이밍 반격: 쳐내고 연타, 피해 80 |
| J | 타이밍 반격: 잡아 메치기, 피해 80 |
| K | 타이밍 반격: 단검 반격, 피해 80 |
| L | 타이밍 반격: 회전 발차기, 피해 80 |
| 상단 숫자 / 숫자패드 1~9 | 해당 수만큼 적 소환, 맵 양 끝·완전히 열린 문 중 무작위 |
| N | 현재 맵의 스테이지 이동 화살표 표시 |
| P | 주인공 무적 ON/OFF 전환, F5 재시작 시 OFF |
| F3 | 첫 맵의 일반 문·창고 문을 함께 열기/닫기 |
| F4 | 바닥 이동 범위 선 표시/숨김 전환 |
| G | 가까운 바닥 무기 획득/교체, 대상이 없으면 보유 무기 버리기 |
| U | 조작/공격 설명 숨김·표시, 주인공/적 HP바 표시 |
| F5 | 플레이·피격·사망 중 처음부터 다시 시작 |
| 창 닫기 | 종료 |

적은 **숫자 1~9를 누를 때 그 수만큼 맵 양 끝 또는 완전히 열린 문에서 무작위로 등장**합니다. 첫 맵의 F3 열기 완료 후에는 일반 문·창고 문과 좌우 반전 구간의 문도 출현 후보가 됩니다. 2층 문에서는 2층 적이 나오며, 닫힘/열리는 중/닫히는 중인 문은 제외합니다. 예를 들어 3을 누르면 3명, 놓았다가 5를 누르면 5명이 추가됩니다. 출현 지점마다 독립 추첨하므로 한 곳에 몰릴 수도 있습니다. 자동 생성은 없고 0은 생성하지 않습니다. 숫자를 길게 누르면 추가 소환되지 않습니다. 주인공 HP는 500이고, 적의 유효 공격마다 20씩 감소합니다. HP가 0이면 쓰러지면서 같은 층의 반경 160px 이내 적들만 바깥쪽으로 밀어냅니다. 멀리 있는 적은 제자리에서 대기합니다.

- 걷기는 300px/s, 달리기는 720px/s의 전체 바닥 속도입니다. 대각선은 정규화하여 빨라지지 않으며 방향키 해제·방향 전환·Shift 해제에 강한 제동을 적용합니다.
- 일반 두 번째 점프는 600→850px/s, 달리기 두 번째 점프는 780→1000px/s로 강화했습니다. 적에게 둘러싸이면 방향키를 유지하면서 Space를 빠르게 두 번 눌러 넘어가세요. Shift도 유지하면 더 멀리 뛰어넘습니다.
- 좌우/상하 반대 입력은 해당 축을 중립으로 처리합니다. Space·공격 키·F5를 길게 눌러도 동작이 반복되지 않습니다.
- 피격 중에는 이동·점프를 잠시 제한합니다. 점프 중 피격되어도 중력은 계속 적용됩니다.
- 여러 적의 공격은 각각 20 피해를 줍니다. 2명이 동시에 맞히면 40, 4명이면 80이 감소하며 피격 모션 중에도 다른 공격의 피해가 적용됩니다. 같은 적의 같은 공격은 한 번만 피해를 줍니다.
- 적은 바닥의 x·ground_y 거리 360px 이상에서 360·420·480·540px/s를 순환 배정한 전체 속도로 달려옵니다. 220px 이내에서는 120px/s 걷기로 돌아오고 두 거리 사이에서는 기존 추격 모드를 유지합니다.
- 여러 적은 좌우 공격 슬롯과 실제 바닥 레인에 분산됩니다. 기본 열은 65px·123px이며 깊이 목표는 보행 영역과 주인공의 ±28px 안으로 압축합니다. 공격 중 심한 겹침은 평면 전체 최대 18px/s로 보정하고, 밀집해도 바닥 밖으로 밀지 않습니다.
- 창 포커스를 잃으면 눌린 키를 해제하여 이동이 고정되는 현상을 방지합니다.
- F5는 첫 스테이지로 돌아와 HP·위치·모든 맵의 적·누적 소환 수·화살표·카메라·효과·무적·반격·입력을 초기화합니다. 다시 숫자를 누르기 전에는 적이 나오지 않습니다. 사망 중에는 적을 소환할 수 없습니다.

비무장 기본 공격은 **A 왼손 잽 / S 오른손 스트레이트 / D 왼발 차기 / F 오른발 차기**입니다. 4Moves 시트에서 각각 3/4/1/2행을 사용합니다. 화면 오른쪽 위의 안내에 현재 보유 무기에 맞는 기술명과 실제 설정 피해량을 표시합니다.

**Q/W/E/R/T는 강화 기본 공격이며 모두 피해 50입니다.** 비무장/단검/쇠파이프 상태에서 사용할 수 있고, 기존 적은 아래 전용 피격 행을 재생합니다. 도시의 enemy02는 강화 피격과 W 동반/해제 중에도 자신의 시트(`HOOD_MAN_enemy02.png`) 6행 피격 모습을 유지합니다.

| 키 | 기술 | 주인공 행 | 적 피격 행 | 피해 |
| --- | --- | --- | --- | --- |
| Q | 두 주먹을 뒤로 모았다 앞으로 내지르기 | 1 | 1 | 50 |
| W | 도약해 양주먹으로 밀쳐 넉백 | 2 | 5 | 50 |
| E | 공중 연속 발차기 | 3 | 4 | 50 |
| R | 아래에서 위로 양주먹 올려치기 | 4 | 2 | 50 |
| T | 어퍼컷 | 5 | 3 | 50 |

강화 공격과 적 피격은 16 FPS·8프레임·약 0.5초로 재생하며 도약/상승 자세의 원본 높이를 보존합니다. E의 연속 발차기도 전체 모션당 적별 한 번, 총 50 피해입니다. W는 공격 방향으로 적을 실제로 밀어내며 경계 안에서 감속합니다. 생존 적은 원래 시트/AI로 돌아가고, 치명타는 지정 피격 후 원래 사망 모션과 페이드를 진행합니다. 일반/강화 공격끼리 새 키로 즉시 전환할 수 있고, 완료 후에는 보유 무기의 대기로 돌아갑니다. 오른쪽 위에 다섯 기술명/피해량이 표시됩니다.

**W를 누르고 있으면 좌우로만 비행하며 ←/→로 방향을 전환합니다.** ↑/↓는 무시하고, 대각선 입력도 좌우 720px/s 이동으로 처리합니다. 접촉한 적은 50 피해를 한 번 받은 뒤 같은 바닥 깊이의 앞쪽에 동반됩니다. 방향키만 놓으면 마지막 좌우 방향을 유지하고, W를 놓으면 주인공은 즉시 멈추며 적은 그 좌우 방향으로 짧게 밀린 뒤 복귀합니다. W 종료 후 일반 걷기의 상하·대각선 이동은 그대로 사용할 수 있습니다.

**바닥 무기에 접근해 G를 누르면 해당 무기의 이동 시트와 A/S/D 공격으로 전환됩니다.** 다른 바닥 무기가 가까이 있으면 G로 교체하고, 가까운 무기가 없으면 버립니다. 점프 중 버린 무기는 중력으로 낙하합니다.

새 게임과 F5 재시작 시 **각 맵에 단검·쇠파이프 합계 15개**를 배치합니다. 두 종류를 최소 한 개씩 포함하며 종류·위치·방향은 무작위입니다. 출구 화살표 영역은 비워 두고, 재방문만으로 아이템을 보충하지 않습니다.

**몽둥이 하나를 든 일반 적을 처치하면 몽둥이 1개를 떨어뜨립니다.** `HoodMan_MetalClub_Item_6frames_1536x256.png`의 6프레임을 사용하며, 사망 위치에서 떨어져 해당 층 바닥에 남습니다. 현재는 드롭 표시만 구현해 **줍기·장착·파밍 기능이나 G 안내는 없습니다.** 몽둥이 두 개를 든 도시 적은 제외하고 초기 배치 15개는 그대로 유지합니다. F5는 사망 드롭을 지웁니다.

| 키 | 단검 | 쇠파이프 | 피해 / FPS |
| --- | --- | --- | --- |
| A | 찌르기(7행) | 찌르기(6행) | 10 / 32 |
| S | 베기(8행) | 휘두르기(7행) | 40 / 20 |
| D | 도약 내려찌르기(9행) | 도약 내려치기(8행) | 50 / 14 |

무기 공격은 적별 한 번 타격하며 단검은 기존 `punch_kick_hit`, 쇠파이프는 기존 `club_hit` 효과를 사용합니다. F는 오른발 차기(60)입니다. 무기를 버리거나 종류를 바꾸면 진행 중인 공격을 취소하고, 비무장 A/S/D 또는 새 무기의 공격으로 전환합니다. 제압 중 A는 반격 후속 공격(80)입니다. F5로 비무장과 초기 바닥 배치를 복원합니다.

**무기 내려찍기는 `Space → Space → D → 방향키 조준 → D` 순서로 사용합니다.** 단검/쇠파이프를 들고 직접 이단 점프한 뒤 D를 누르면 시간이 **0.2배**로 느려집니다. 주인공과 적의 이동·중력·애니메이션이 함께 느려지고, 방향키·대각선·Shift로 공중 이동과 방향 전환이 가능합니다.

D를 놓았다가 다시 누르면 시간이 **2배**로 가속되며 선택한 방향으로 급강하합니다. 방향키를 놓으면 마지막 조준 방향을 사용하고, 한 번도 조준하지 않았다면 바라보는 방향을 사용합니다. 급강하 방향은 발동 순간 고정되며 실제 착지 후 50 피해를 적별 한 번 적용합니다. 공격 종료 후 정상 속도로 복귀합니다. 지상/첫 점프에서의 D는 발동하지 않으며, D 유지·키 반복이나 추가 Space로 공격/점프가 반복되지 않습니다. 두 번째 D 없이 착지하거나 G 버리기·다른 공격·피격·사망으로 중단되면 시간도 정상으로 복원됩니다. 화면 하단에 현재 조작 단계가 표시됩니다.

**두 번째 D로 급강하할 때는 무기를 든 주인공의 잔상이 이동 경로에 남습니다.** 반투명 자세가 연속으로 표시되고 오래된 잔상부터 서서히 사라집니다. 착지/공격 중단 후 남은 잔상도 자연스럽게 사라지며, U로 설명을 숨겨도 효과가 표시됩니다. 생성 간격·수명·진하기는 `config.py`의 `WEAPON_DIVE_AFTERIMAGE_*` 값으로 조정합니다.

적은 HP 200이며 머리 위의 작은 빨간 HP바로 표시합니다. **A/S/D/F는 각각 10/40/50/60 피해**를 줍니다. 적중하면 HP바 위에 실제 감소량이 작은 노란 숫자로 나타나 0.45초 동안 살짝 떠오른 뒤 사라집니다. 같은 공격은 각 적에게 한 번만 적용됩니다. HP 0인 적은 쓰러진 뒤 공격하거나 이동을 막지 않습니다.

**적이 쇠파이프를 휘두르는 중에 H/J/K/L을 새로 누르면 반격해 적을 붙잡습니다.** 지상에서 가로 140px·바닥 깊이 차이 32px 이내의 주인공 방향 공격(적 공격 1~5번 프레임)이 대상입니다. 가까운 적 한 명과 같은 행의 준비 모션을 시작한 뒤 **제압 자세에서 멈추고, A를 새로 눌러야 후속 공격으로 80 피해**를 줍니다. A를 누르지 않으면 자세와 적 HP를 그대로 유지합니다.

**제압 유지 중 방향키로 적을 든 채 4방향·대각선 이동**할 수 있습니다. 전체 속도는 180px/s이며 시작 방향을 유지해 뒤로도 걸을 수 있습니다. 적은 앞쪽 80px·높이 24px에 연결되고 두 캐릭터 모두 바닥 경계를 지킵니다. Shift 가속·점프·S/D/F·추가 반격·맵 전환은 제한됩니다. 화면 하단에 이동/A 후속 공격 안내를 표시합니다.

A를 준비 중에 미리 누르거나 계속 유지하면 자동으로 후속 공격하지 않습니다. 제압 후 **A를 놓았다가 새로 누르면 선택한 H/J/K/L 기술의 나머지 모션**을 이어갑니다. 주인공 8 FPS·적 6 FPS로 재생하고, 주인공이 먼저 복귀한 뒤 생존 적은 남은 반응을 마쳐 **IDLE·원래 추적/공격**으로 돌아갑니다. HP 0인 적은 마지막 자세로 3초 대기·1초 페이드 후 사라집니다.

제압 준비/후속 공격은 일반 적 공격에서 잠시 보호하며, **제압을 유지하며 이동할 때는 일반 피격으로 붙잡기가 풀립니다.** P 무적은 별도로 유지됩니다. H를 유지하는 것만으로 자동 반격하지 않으며 실패 입력도 예약하지 않습니다. F5는 제압/이동 중에도 즉시 초기화합니다.

같은 층의 일반 전투에서는 **바닥 깊이 차이가 32px 이내**여야 하며, 좌우 방향·거리·점프 높이·유효 프레임도 판정합니다. 위아래로 이동해 다른 레인의 공격을 피할 수 있고 같은 레인의 여러 적은 동시에 피해를 줍니다.

위치는 `floor`(층), `x`, `ground_y`(바닥), `jump_height`(떠오른 높이)로 나뉩니다. 점프 중에도 바닥을 이동할 수 있으며 화면 발 높이는 두 높이의 합입니다. 첫 맵의 1층 바닥은 y=56~136, 2층은 y=452~502이며 두 층 모두 상하좌우·대각선 이동이 가능합니다. 두 번째 맵은 56~116으로 제한하고 좌우 여백은 주인공 68px·적 88px입니다. 이동·공격 보정·피격·넉백 뒤에도 바닥 위치를 자기 층의 경계 안에 둡니다. 서로 다른 평지 층 사이에서는 타격·반격·몸체 밀기·W 동반이 발생하지 않지만, 계단이나 층간 낙하 중인 적은 실제 높이가 맞으면 주인공에게 맞습니다. 캐릭터는 점프 높이와 관계없이 바닥 y가 큰 뒤쪽부터 그립니다.

공격 도중 **다른 기본 공격 키를 새로 누르면 바로 해당 공격으로 전환**됩니다. 예를 들어 A 직후 S를 누르면 잽이 끝날 때까지 기다리지 않고 스트레이트가 시작됩니다. 한 번의 물리 갱신 전에 여러 공격 키가 들어오면 마지막 새 입력을 적용합니다. 키 유지·반복이나 진행 중인 공격과 같은 키의 재입력은 모션을 재시작하거나 다음 공격을 예약하지 않습니다.

잽 A는 **32 FPS·약 0.250초**, 스트레이트 S는 **20 FPS·약 0.400초**, 발차기 D/F는 **14 FPS·약 0.571초**로 재생합니다. 무기 A/S/D도 각각 32/20/14 FPS입니다. 기본 공격/반격 적중에는 최대 8px·0.2초, 주인공 피격에는 최대 16px·0.2초의 **카메라 흔들림**이 발생하며 타격 종류에 따라 기존 `punch_kick_hit`·`club_hit` 효과가 나타납니다.

**P를 누를 때마다 무적이 켜지거나 꺼집니다.** 무적 중에는 모든 방향의 적 공격 피해를 받지 않으며 HP 수치 아래에 `무적 ON`이 표시됩니다. 시작과 F5 재시작 시에는 OFF입니다.

**F4를 누르면 바닥 이동 범위를 선으로 표시하고, 다시 누르면 숨깁니다.** 하늘색 실선은 주인공, 주황색 점선은 적의 발 이동 한계입니다. 첫 맵에서는 1층 y=56~136과 2층 y=452~502, 주인공 좌우 x=68~2492, 적 좌우 x=88~2472를 함께 표시하고 계단 경로는 연두색입니다. 선은 카메라 이동·흔들림을 따라가지만 점프 높이와는 무관합니다. P 무적과 독립적이며 표시 선택은 맵 이동/F5에도 유지됩니다. U로 설명을 숨겨도 F4 선은 유지됩니다.

**첫 맵의 문은 처음에 모두 닫혀 있고 F3로 열기·닫기를 전환합니다.** 1층 일반 문 1개·2층 일반 문 2개·창고 셔터 1개가 함께 동작합니다. 두 시트의 1행은 열기, 2행은 닫기이며 각각 8프레임·12 FPS입니다. 키 유지/반복에는 다시 전환하지 않고, 애니메이션 중 새로 누르면 현재 자세에서 반대로 재생합니다. 맵을 떠나면 멈추고 재방문 시 이어지며 F5는 닫힘으로 초기화합니다. 문은 적 출현 지점이며 별도 실내 맵으로 들어가지는 않습니다.

**첫 맵 왼쪽 계단 아래에서 좌우 키를 놓고 ↑를 누르면 2층으로 올라갑니다.** 2층 계단 위에서 ↓를 누르면 내려옵니다. 진입한 뒤에는 키를 놓아도 끝까지 자동으로 걸으며 도중 공격·점프·무기 교환은 예약하지 않습니다. 주인공은 단독으로 이용하고, 적끼리는 같은 방향에서 **100px 간격을 두고 여러 명이 줄지어 이동**합니다. 앞선 적이 계단을 완전히 벗어나기 전에도 다음 적이 진입할 수 있습니다. 반대 방향이나 주인공의 대기 차례가 오면 현재 대열이 빠진 뒤 진입하며 뒤의 적이 순서를 건너뛰지 않습니다. 기다리는 중 ↑/↓를 놓거나 입구를 떠나면 주인공의 대기를 취소합니다. 다른 층의 적은 계단 또는 아래의 직접 낙하로 추적하고 도착 후 전투를 재개합니다. 2층에서도 점프·공격·무기 획득/버리기가 가능하며 N 스테이지 출구는 1층에서만 이용합니다. F5는 모든 이용자의 진행·대기를 초기화합니다.

적은 계단 입구까지 각자의 달리기 속도를 유지하고, 진입 간격이나 통행 차례를 기다려야 하면 지정 대기 위치에서 멈춥니다. 입구 근처라는 이유로 걷기로 감속하거나 이동 중 대기 자세를 표시하지 않습니다. 계단 위의 이동 속도와 선착순 규칙은 그대로입니다.

**계단을 오르거나 내려오는 적도 실제 공격 범위 안에 있으면 맞습니다.** 비무장·무기·강화 공격과 W 접촉에 적용하며, 일반 피격은 적과 뒤따르는 대열을 잠시 멈춘 뒤 간격을 유지하며 이동을 재개합니다. 강화 피격이나 치명타는 현재 발 높이를 유지한 채 계단에서 떨어뜨립니다. 낙하 중에도 공격할 수 있고 피해 숫자·효과는 실제 적중 높이에 표시합니다. 계단 이용자에 대한 반격과 몸체 밀기는 여전히 제외합니다.

**1층 주인공을 쫓는 2층 적이 여러 명이면 무작위 인원으로 계단 이용과 직접 낙하를 나눕니다.** 새로 경로를 정할 적이 N명일 때 1~N−1명을 낙하로 선택하고 나머지는 계단을 이용합니다. 경로는 매 프레임 다시 뽑지 않습니다. 낙하 대상은 0~0.35초의 개별 간격을 두고 앞쪽 가장자리로 이동해 중력으로 내려오며, 공중에서도 주인공 쪽으로 좌우 추적합니다. 낙하 피해는 없고 착지 후 일반 추적·공격을 재개합니다. 혼자 경로를 정할 때는 계단을 이용합니다.

**계단 없이도 `Space → Space → ↑`로 2층에 올라갈 수 있습니다.** 이단 점프 후 ↑로 2층 착지를 선택하고 ←/→로 방향을 바꾸세요. 발이 2층 앞쪽 발판 높이(y=452)를 위에서 아래로 통과할 때 착지하며, 상승 중에는 발판 밑면에 걸리지 않습니다. ↑를 놓고 좌우로 조향해도 착지 선택을 유지하고, 공중에서 ↓를 누르면 취소합니다. ↑ 없이 이단 점프하면 1층으로 돌아옵니다.

첫 맵 1층의 일반 이단 점프는 두 번째 Space의 시점과 무관하게 2층에 닿도록 높이를 보정합니다. 바닥 깊이와 분리된 같은 점프 곡선을 사용하며 캐릭터는 화면 상단 안에 머뭅니다. 2층과 다른 맵의 기존 점프 속도는 유지합니다. 이단 점프의 2층 착지는 주인공만 사용하고 적의 계단 추적·간격 이동에는 영향을 주지 않습니다.

**2층에서 ↓로 앞쪽 가장자리를 넘으면 1층으로 떨어집니다.** 바닥 안쪽에서는 기존처럼 걸으며, 가장자리에서만 중력을 따라 낙하합니다. 내려오는 중 좌우 조향이 가능하고 낙하 피해는 없지만 추가 점프나 즉시 2층 재착지는 할 수 없습니다. 계단 입구의 ↓는 기존 계단 내려오기를 우선합니다. F5는 낙하/착지 선택도 초기화합니다.

## 스테이지 이동

1. 첫 맵 `HoodMan_2F_Map_1672x941.png`에서 **N**을 누르면 맵 맨 오른쪽에 노란 오른쪽 화살표가 나타납니다.
2. 오른쪽 끝으로 이동하면 `newStage-2.png`의 왼쪽에서 이어집니다.
3. 두 번째 맵에서 **N을 놓았다가 다시 누르면** 양쪽 끝에 화살표가 나타납니다. 왼쪽 끝으로 이동하면 첫 맵 오른쪽으로 돌아옵니다.

전환 중에도 **걷기·달리기 속도, 점프 높이·상승/하강 속도·남은 점프 횟수, HP와 애니메이션 진행 상태**를 이어갑니다. 방향키·Shift·Space를 유지해도 입력이 끊기지 않습니다. 맵마다 소환한 적의 체력·효과·소환 순서·N 표시 상태는 보존하며, 떠난 맵의 시뮬레이션은 일시 정지합니다.

기존 첫 배경 `changed_first_map.png`와 `newStage.png`는 프로젝트 루트에 그대로 보존하며 이동하거나 삭제하지 않습니다. 새 맵에서 허용되지 않는 바닥 깊이만 경계 안으로 옮기고 점프 높이와 속도는 이어갑니다. 예를 들어 첫 맵 바닥 y=136에서 두 번째로 넘어가면 바닥만 116이 됩니다.

두 번째 맵의 오른쪽 출구는 **2초 로딩 화면** 뒤 `cityStage-1.png`로 이어지고, 도시 첫 맵의 오른쪽 출구는 `cityStage-2.png`로 이어집니다. 네 맵을 왕복할 수 있으며 기존/도시 구역 경계에서는 양방향 2초 로딩을 표시합니다. 마지막 도시 맵 오른쪽은 이동 대상이 없는 표식입니다. 화살표는 맵 바닥에서 살짝 좌우로 움직입니다.
