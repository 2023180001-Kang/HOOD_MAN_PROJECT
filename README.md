# HOOD_MAN_PROJECT

Python과 pico2d로 구현한 2.5D 벨트스크롤 액션 게임입니다. 개발 명세는 [PRD.md](PRD.md), 단계별 기록은 [DEVELOPMENT.md](DEVELOPMENT.md), 검증 결과는 [TESTING.md](TESTING.md)를 참고하세요.

## 실행 환경

- Windows 64비트
- 확인한 버전: Python 3.13.15, pico2d 1.5.1
- 1280×720 창, 60 FPS 렌더링 목표, 120Hz 고정 물리 갱신

## 설치와 실행 (PowerShell)

프로젝트 폴더에서 실행합니다. Python이 없다면 Python 3.13 64비트를 먼저 설치합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

리소스는 소스 파일 위치를 기준으로 읽으므로 다른 작업 폴더에서 `main.py`의 전체 경로로 실행해도 됩니다.
일반 실행 시 타이틀 이미지를 2초 표시한 뒤 자동으로 게임이 시작됩니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| ← / → | 바닥 좌우 걷기 |
| ↑ / ↓ | 바닥 안쪽 / 바깥쪽 걷기, 좌우와 조합해 대각선 이동 |
| 왼쪽/오른쪽 Shift + 방향키 | 가속하여 달리기 |
| Space | 점프, 공중에서 다시 누르면 이단 점프 |
| A | 평소 왼손 잽(10), 제압 유지 중에는 선택한 반격의 후속 공격(80) |
| S | 오른손 스트레이트, 피해 40 |
| D | 왼발 차기, 피해 50 |
| F | 오른발 차기, 피해 60 |
| H | 타이밍 반격: 쳐내고 연타, 피해 80 |
| J | 타이밍 반격: 잡아 메치기, 피해 80 |
| K | 타이밍 반격: 단검 반격, 피해 80 |
| L | 타이밍 반격: 회전 발차기, 피해 80 |
| 상단 숫자 / 숫자패드 1~9 | 해당 수만큼 적 소환, 각 적의 등장 방향은 무작위 좌우 |
| N | 현재 맵의 스테이지 이동 화살표 표시 |
| P | 주인공 무적 ON/OFF 전환, F5 재시작 시 OFF |
| F5 | 플레이·피격·사망 중 처음부터 다시 시작 |
| 창 닫기 | 종료 |

적은 **숫자 1~9를 누를 때 그 수만큼 맵 양 끝 중 무작위 위치에서 등장**합니다. 예를 들어 3을 누르면 3명, 놓았다가 5를 누르면 5명이 추가됩니다. 각 적의 방향을 따로 뽑으므로 한쪽에 몰릴 수도 있습니다. 자동 생성은 없고 0은 생성하지 않습니다. 숫자를 길게 누르면 추가 소환되지 않습니다. 주인공 HP는 500이고, 적의 유효 공격마다 20씩 감소합니다. HP가 0이면 쓰러지면서 반경 160px 이내의 가까운 적들만 바깥쪽으로 밀어냅니다. 멀리 있는 적은 제자리에서 대기합니다.

- 걷기는 300px/s, 달리기는 720px/s의 전체 바닥 속도입니다. 대각선은 정규화하여 빨라지지 않으며 방향키 해제·방향 전환·Shift 해제에 강한 제동을 적용합니다.
- 일반 두 번째 점프는 600→850px/s, 달리기 두 번째 점프는 780→1000px/s로 강화했습니다. 적에게 둘러싸이면 방향키를 유지하면서 Space를 빠르게 두 번 눌러 넘어가세요. Shift도 유지하면 더 멀리 뛰어넘습니다.
- 좌우/상하 반대 입력은 해당 축을 중립으로 처리합니다. Space·공격 키·F5를 길게 눌러도 동작이 반복되지 않습니다.
- 피격 중에는 이동·점프를 잠시 제한합니다. 점프 중 피격되어도 중력은 계속 적용됩니다.
- 여러 적의 공격은 각각 20 피해를 줍니다. 2명이 동시에 맞히면 40, 4명이면 80이 감소하며 피격 모션 중에도 다른 공격의 피해가 적용됩니다. 같은 적의 같은 공격은 한 번만 피해를 줍니다.
- 적은 바닥의 x·ground_y 거리 360px 이상에서 360·420·480·540px/s를 순환 배정한 전체 속도로 달려옵니다. 220px 이내에서는 120px/s 걷기로 돌아오고 두 거리 사이에서는 기존 추격 모드를 유지합니다.
- 여러 적은 좌우 공격 슬롯과 실제 바닥 레인에 분산됩니다. 기본 열은 65px·123px이며 깊이 목표는 보행 영역과 주인공의 ±28px 안으로 압축합니다. 공격 중 심한 겹침은 평면 전체 최대 18px/s로 보정하고, 밀집해도 바닥 밖으로 밀지 않습니다.
- 창 포커스를 잃으면 눌린 키를 해제하여 이동이 고정되는 현상을 방지합니다.
- F5는 첫 스테이지로 돌아와 HP·위치·모든 맵의 적·누적 소환 수·차량/통행 대기·화살표·카메라·효과·무적·반격·입력을 초기화합니다. 다시 숫자를 누르기 전에는 적이 나오지 않습니다. 사망 중에는 적을 소환할 수 없습니다.

기본 공격은 **A 왼손 잽 / S 오른손 스트레이트 / D 왼발 차기 / F 오른발 차기**입니다. 새 4Moves 시트에서 각각 3/4/1/2행을 사용합니다. 화면 오른쪽 위의 안내에 기술명과 실제 설정 피해량을 표시합니다. Q/W/E/R에는 동작이 연결되어 있지 않습니다.

적은 HP 200이며 머리 위의 작은 빨간 HP바로 표시합니다. **A/S/D/F는 각각 10/40/50/60 피해**를 줍니다. 적중하면 HP바 위에 실제 감소량이 작은 노란 숫자로 나타나 0.45초 동안 살짝 떠오른 뒤 사라집니다. 같은 공격은 각 적에게 한 번만 적용됩니다. HP 0인 적은 쓰러진 뒤 공격하거나 이동을 막지 않습니다.

**적이 쇠파이프를 휘두르는 중에 H/J/K/L을 새로 누르면 반격해 적을 붙잡습니다.** 지상에서 가로 140px·바닥 깊이 차이 32px 이내의 주인공 방향 공격(적 공격 1~5번 프레임)이 대상입니다. 가까운 적 한 명과 같은 행의 준비 모션을 시작한 뒤 **제압 자세에서 멈추고, A를 새로 눌러야 후속 공격으로 80 피해**를 줍니다. A를 누르지 않으면 자세와 적 HP를 그대로 유지합니다.

**제압 유지 중 방향키로 적을 든 채 4방향·대각선 이동**할 수 있습니다. 전체 속도는 180px/s이며 시작 방향을 유지해 뒤로도 걸을 수 있습니다. 적은 앞쪽 80px·높이 24px에 연결되고 두 캐릭터 모두 바닥 경계를 지킵니다. Shift 가속·점프·S/D/F·추가 반격·맵 전환은 제한됩니다. 화면 하단에 이동/A 후속 공격 안내를 표시합니다.

A를 준비 중에 미리 누르거나 계속 유지하면 자동으로 후속 공격하지 않습니다. 제압 후 **A를 놓았다가 새로 누르면 선택한 H/J/K/L 기술의 나머지 모션**을 이어갑니다. 주인공 8 FPS·적 6 FPS로 재생하고, 주인공이 먼저 복귀한 뒤 생존 적은 남은 반응을 마쳐 **IDLE·원래 추적/공격**으로 돌아갑니다. HP 0인 적은 마지막 자세로 3초 대기·1초 페이드 후 사라집니다.

제압 준비/후속 공격은 일반 적 공격에서 잠시 보호하며, **제압을 유지하며 이동할 때는 일반 피격으로 붙잡기가 풀립니다.** P 무적은 별도이고 차량 충돌은 모든 단계에서 즉사합니다. H를 유지하는 것만으로 자동 반격하지 않으며 실패 입력도 예약하지 않습니다. F5는 제압/이동 중에도 즉시 초기화합니다.

서로 공격하려면 **바닥 깊이 차이가 32px 이내**여야 하며, 좌우 방향·거리·점프 높이·유효 프레임도 판정합니다. 위아래로 이동해 다른 레인의 공격을 피할 수 있고 같은 레인의 여러 적은 동시에 피해를 줍니다.

위치는 `x`, `ground_y`(바닥), `jump_height`(떠오른 높이)로 나뉩니다. 점프 중에도 바닥을 이동할 수 있으며 화면 발 높이는 두 높이의 합입니다. 첫 맵은 바닥 y=56~148, 두 번째는 56~116으로 제한하고 좌우 여백은 주인공 68px·적 88px입니다. 이동·공격 보정·피격·넉백 뒤에도 발을 경계 안에 둡니다. 캐릭터는 점프 높이와 관계없이 바닥 y가 큰 뒤쪽부터 그립니다.

공격 도중 **다른 기본 공격 키를 새로 누르면 바로 해당 공격으로 전환**됩니다. 예를 들어 A 직후 S를 누르면 잽이 끝날 때까지 기다리지 않고 스트레이트가 시작됩니다. 한 번의 물리 갱신 전에 여러 공격 키가 들어오면 마지막 새 입력을 적용합니다. 키 유지·반복이나 진행 중인 공격과 같은 키의 재입력은 모션을 재시작하거나 다음 공격을 예약하지 않습니다.

잽 A는 **32 FPS·약 0.250초**, 스트레이트 S는 **20 FPS·약 0.400초**, 발차기 D/F는 **14 FPS·약 0.571초**로 재생합니다. 기본 공격/반격 적중에는 최대 8px·0.2초, 주인공 피격에는 최대 16px·0.2초의 **카메라 흔들림**이 발생하며 실제 피해에는 제공된 `blood_hit` 효과가 나타납니다.

**P를 누를 때마다 무적이 켜지거나 꺼집니다.** 무적 중에는 모든 방향의 적 공격 피해를 받지 않으며 HP 수치 아래에 `무적 ON`이 표시됩니다. 시작과 F5 재시작 시에는 OFF입니다.

## 스테이지 이동

1. 첫 맵 `newStage.png`에서 **N**을 누르면 맵 맨 오른쪽에 노란 오른쪽 화살표가 나타납니다.
2. 오른쪽 끝으로 이동하면 `newStage-2.png`의 왼쪽에서 이어집니다.
3. 두 번째 맵에서 **N을 놓았다가 다시 누르면** 양쪽 끝에 화살표가 나타납니다. 왼쪽 끝으로 이동하면 첫 맵 오른쪽으로 돌아옵니다.

전환 중에도 **걷기·달리기 속도, 점프 높이·상승/하강 속도·남은 점프 횟수, HP와 애니메이션 진행 상태**를 이어갑니다. 방향키·Shift·Space를 유지해도 입력이 끊기지 않습니다. 맵마다 소환한 적의 체력·효과·소환 순서·N 표시 상태는 보존하며, 떠난 맵의 시뮬레이션은 일시 정지합니다.

새 맵에서 허용되지 않는 바닥 깊이만 경계 안으로 옮기고 점프 높이와 속도는 이어갑니다. 예를 들어 첫 맵 바닥 y=145에서 두 번째로 넘어가면 바닥만 116이 됩니다.

두 번째 맵의 오른쪽 출구는 **2초 로딩 화면** 뒤 `cityStage-1.png`로 이어지고, 도시 첫 맵의 오른쪽 출구는 `cityStage-2.png`로 이어집니다. 네 맵을 왕복할 수 있으며 기존/도시 구역 경계에서는 양방향 2초 로딩을 표시합니다. 마지막 도시 맵 오른쪽은 이동 대상이 없는 표식입니다. 화살표는 맵 바닥에서 살짝 좌우로 움직입니다.

## 도시 도로 차량

- **cityStage-1의 도로에서 차량이 무작위로 왼쪽 또는 오른쪽으로 통과합니다.** 첫 차는 0.35초 후 생성되고 한 대씩 1120~1680px/s로 달리며, 맵을 빠져나간 뒤 0.4~1.0초를 기다리고 다음 차가 들어옵니다.
- **cityStage-1의 적은 좌우 끝의 인도(y=100~148)에서 소환**되어 차량 도로 위에 생성되지 않습니다. 생성 이후에는 전체 바닥에서 주인공을 추적합니다.
- ↓로 도로에 내려가 차체에 닿으면 주인공과 적 모두 **즉시 HP 0**이 되고 각자의 새 차량 피격 8프레임이 재생됩니다. 차 방향으로 밀려난 뒤 마지막 자세를 유지하며, 적은 3초 대기·1초 페이드 후 사라집니다. **P 무적과 반격 중에도 차량은 즉사 판정**입니다.
- ↑로 올라간 인도는 안전하고, 충분히 높게 이단 점프하면 차체를 피할 수 있습니다. 숫자로 소환한 적을 도로 쪽으로 유인해 차에 치이게 할 수도 있습니다. 맵을 떠나거나 로딩 중에는 차량이 멈추고 F5는 전체 차량 상태를 초기화합니다.

## 개발 검증

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe tools/prepare_assets.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe main.py --smoke-test 60
.\.venv\Scripts\python.exe tools/check_render.py
.\.venv\Scripts\python.exe tools/check_runtime.py
.\.venv\Scripts\python.exe tools/check_damage_numbers.py
.\.venv\Scripts\python.exe tools/check_enemy_spacing.py
.\.venv\Scripts\python.exe tools/check_belt_scroll.py
.\.venv\Scripts\python.exe tools/check_stages.py
.\.venv\Scripts\python.exe tools/check_counters.py
.\.venv\Scripts\python.exe tools/check_traffic.py
```

원본 PNG를 보존하며 `assets/frames.json`의 프레임별 클립 좌표를 생성합니다. 생성된 파일이 저장소에 포함되어 있어 일반 실행에는 Pillow가 필요하지 않습니다. 스모크 테스트는 실제 pico2d 창에서 지정한 프레임을 렌더링하고 정상 종료합니다.

`check_render.py`는 주요 상태의 실제 렌더링 화면을 `artifacts/`에 저장합니다. `check_runtime.py`는 ASDF 동작·연속 전환·공격별 속도·10/40/50/60 피해·대상 없는 반격 입력·SDL 키 이벤트·HP바 픽셀·포커스·재시작·정상 종료를 검사하고 적 4명 상황의 FPS를 출력합니다. `check_damage_numbers.py`는 피해 숫자를, `check_stages.py`는 네 배경·왕복·2초 로딩을 검증합니다. `check_counters.py`는 네 반격의 제압 유지·적을 든 이동·새 A 후속 80·치명타/페이드·피격/차량/F5 중단·양 끝 경계·제압 이동 성능을 실제 창에서 검증합니다.

`check_traffic.py`는 실제 창에서 차량 8프레임·양방향 반전/랜덤 통행·주인공/적 즉사·전용 마지막 자세·시체 페이드 픽셀·SDL 도로 진입/이단 점프/F5를 검증합니다. `artifacts/traffic_*.png` 캡처와 차량/적 4명 성능 결과를 출력합니다.
